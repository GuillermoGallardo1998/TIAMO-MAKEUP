## 📌 Description

Professional landing page for **Nahomy Tiamo**, a professional makeup artist. The page showcases her services (wedding, social, artistic, full glam), experiences gallery, contact form, and booking system, along with an integrated AI chatbot 🤖 that allows users to ask questions in real time about services, portfolio, and general information.

This project was **developed almost entirely locally**, with careful hand-coding of all components, animations, and interactivity using **CSS and JavaScript**, without relying on external animation libraries. The deployed version represents **almost the exact result from local development**, ensuring high fidelity between development and production.

CSS is organized using the **BEM (Block, Element, Modifier) methodology**, ensuring a scalable and maintainable style architecture.

Developed with **React**, **Vite**, **modular CSS**, and **plain JavaScript**, and supported by a **Node.js + Express backend deployed on Render**, connected to the **Gemini API** to power the chatbot experience.

The project emphasizes **high performance**, **accessibility**, **SEO best practices**, and follows **clean code standards with ESLint**. It is deployed on **Firebase Hosting** and integrates **EmailJS** for the contact form, creating a complete, automated, and interactive user experience.

## 🛠️ Technologies Used

- **Frontend:** React, Vite, JavaScript (ES6+), Modular CSS (BEM Methodology)
- **Backend:** Node.js, Express (deployed on Render)
- **AI Integration:** Gemini API (Google Generative AI)
- **State & Logic:** React Hooks (useState, useEffect)
- **Deployment & Hosting:** Firebase Hosting  
- **Form Integration:** EmailJS  
- **Code Quality:** ESLint  
- **Animations & Interactivity:** CSS Animations, Dynamic JavaScript Behaviors, React Hot Toast (Notifications)

## 📧 Personalized Email Automation

<p align="center">
  <img src="https://i.imgur.com/TkIZuYj.png" width="800" alt="Tiamo Makeup Landing Page Preview">
</p>

The landing page includes a contact form integrated with **EmailJS**, allowing users to send messages directly without a custom backend.

Each submission triggers a **personalized email** with user-provided data, ensuring quick communication and a seamless booking experience. This feature automates client interaction and improves response time for inquiries and service requests.

## 🤖 AI Chatbot

<p align="center">
  <img src="https://i.imgur.com/85xMT2D.png" width="800" alt="Chat Bot Tiamo Makeup">
</p>

This project includes an integrated AI chatbot that allows users to interact directly within the landing page and ask questions in real time about services, portfolio, and general information.

The chatbot is powered by a **Node.js + Express backend deployed on Render**, which connects to the **Gemini API** to generate dynamic and contextual responses. It enhances user experience by providing instant assistance and automating customer support without leaving the website.
